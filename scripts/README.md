# ⚙️ Automation Scripts

This directory contains the internal Python and Bash scripts used to maintain, validate, and generate this repository.

## 🎯 What's Inside
- `validate_skills.py`: A CI/CD script that parses every `.md` file to ensure it adheres to the strict Big Tech Template.
- JSON Builders: Scripts that dynamically compile the 400+ skills into `skills_bundle.json`.

*Note: These scripts are primarily for repository maintainers and GitHub Actions. End-users do not need to run these to use the Claude Skills.*

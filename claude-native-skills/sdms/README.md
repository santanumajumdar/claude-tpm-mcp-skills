# 📈 Software Development Manager (SDM) Skills

Welcome to the SDM skills directory! This folder contains 100 Agent Personas tailored for Engineering Managers and SDMs scaling teams.

## 🎯 What's Inside
These skills focus on engineering velocity and team health:
- Identifying PTO bottlenecks and burnout
- Aggregating DORA metrics
- Optimizing pair programming schedules
- Generating Promotion Packets

## 🚀 How to Use
1. Download a `.md` file from this folder.
2. Upload it via the **"Upload skill"** button in Claude.
3. Provide your team's Git logs, Jira sprint data, or HR extracts to generate insights.

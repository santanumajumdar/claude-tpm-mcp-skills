# 💡 Product Manager (PM) Skills

Welcome to the PM skills directory! This folder contains 100 specialized Agent Personas tailored for Product Managers driving 0-to-1 launches.

## 🎯 What's Inside
These skills transform Claude into an elite product strategist capable of:
- Slicing PRDs into engineering user stories
- Categorizing NPS feedback using NLP
- Calculating A/B test significance
- Designing Go-To-Market (GTM) syncs

## 🚀 How to Use
1. Download any `.md` file from this folder.
2. Upload it via the **"Upload skill"** button in the Claude Web UI / Enterprise.
3. Feed it your raw user research, telemetry, or feature requests.

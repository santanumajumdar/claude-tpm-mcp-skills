# 🌟 Claude Native Skills (Tier 1: No-Code)

Welcome to the **Claude Native Skills** directory! 

While the root of this repository focuses on advanced Model Context Protocol (MCP) servers that require local Python execution, this specific folder is designed for **100% No-Code usage**. 

These skills are pure prompt-based Agent Personas. They contain highly rigorous instructions, constraints, and step-by-step algorithms, but they *do not* require you to run any local code or configure API keys.

## 📂 Available Roles

We have compiled 400+ native skills across major Big Tech roles:

- 📁 **[TPMs (100 Skills)](./tpms)**: Technical Program Managers
- 📁 **[PMs (100 Skills)](./pms)**: Product Managers
- 📁 **[SDMs (100 Skills)](./sdms)**: Software Development Managers / Engineering Managers
- 📁 **[SDEs (100 Skills)](./sdes)**: Software Engineers
- 📁 **[Executives (5 Skills)](./executives)**: C-Suite Personas (CTO, CISO, VPE, CPO, CRO)

## 🎮 How to Use (Direct Upload)

These files are perfectly formatted to be ingested directly by Claude's native Skill manager.

1. Navigate to the folder of your role (e.g., `/pms`).
2. Download the `.md` file for the skill you want to use (e.g., `user-story-slicer.md`).
3. Open your Claude Enterprise / Claude for Work UI.
4. Click on the **Skills** menu.
5. Click **Add -> Upload skill**.
6. Upload the `.md` file you downloaded.

Claude will immediately adopt the persona, constraints, and algorithmic thinking required to execute that specific Big Tech workflow!

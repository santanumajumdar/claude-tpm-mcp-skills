# 🗂️ Technical Program Manager (TPM) Skills

Welcome to the TPM skills directory! This folder contains 100 highly specialized, pure prompt-based Agent Personas tailored for Technical Program Managers in Big Tech.

## 🎯 What's Inside
These skills transform Claude into an elite execution engine capable of:
- Orchestrating cross-functional dependencies
- Triaging Sev-1 incidents
- Managing AWS/GCP cloud budgets
- Enforcing SOC2 compliance

## 🚀 How to Use
1. Select a `.md` file (e.g., `epic-breakdown-assistant.md`).
2. Download it and upload it via the **"Upload skill"** button in the Claude Web UI / Enterprise.
3. Provide the requested context (e.g., a PRD or a Jira export) and watch Claude execute!

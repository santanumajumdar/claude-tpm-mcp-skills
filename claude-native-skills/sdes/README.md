# 💻 Software Engineer (SDE) Skills

Welcome to the SDE skills directory! This folder contains 100 Agent Personas tailored for Staff/Principal Software Engineers.

## 🎯 What's Inside
These skills force Claude to output production-grade architecture, completely ignoring generic boilerplate:
- Frontend UX Architect (Tailwind/React)
- Playwright Test Generators
- SSRF Vulnerability Scanners
- Monorepo Impact Analyzers

## 🚀 How to Use
1. Download a `.md` file from this folder.
2. Upload it via the **"Upload skill"** button in Claude.
3. Provide your raw code or architecture diagrams and ask Claude to refactor or secure it.

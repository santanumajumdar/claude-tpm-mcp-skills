# Incident Postmortem Generator

This MCP server automates the creation of blameless 5-Whys incident postmortems by analyzing structured event logs, summarizing the timeline, and drafting the core document.

## Features
- **Timeline Extraction:** Reconstructs the timeline of events from raw input data.
- **5-Whys Generation:** Drafts the 5-whys root cause analysis.
- **Action Items:** Recommends preventative action items.

## Usage
Provide the raw incident logs or incident summary, and the tool will structure it into a standard Postmortem format.

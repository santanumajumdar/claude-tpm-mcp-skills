# Tech Debt Quantifier

This MCP server helps engineering managers and TPMs translate abstract technical debt (e.g., SonarQube code smells, missing test coverage, legacy dependencies) into concrete business impact.

## Features
- **Effort Estimation:** Converts code smells to estimated lost engineering hours per month.
- **Risk Assessment:** Flags high-risk legacy dependencies.
- **ROI Calculator:** Calculates the Return on Investment for paying down specific debt items.
